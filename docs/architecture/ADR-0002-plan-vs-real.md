# ADR-0002 · Programación como calendario operativo

**Estado:** ACEPTADO

La programación mensual/semanal de Dirección Operativa se convierte en actividades calendarizadas. Cada actividad puede iniciar, finalizar, completarse, reprogramarse, omitirse con causa o generar incidencia. La app calcula plan vs real por día, semana, mes, persona, planta y proceso.
