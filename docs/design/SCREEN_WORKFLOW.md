# Flujo de diseño por pantalla

1. Definir la pregunta que debe responder.
2. Identificar usuario y contexto.
3. Definir una acción primaria.
4. Definir información imprescindible.
5. Diseñar happy path + vacío/loading/error/permisos.
6. Impeccable `shape`.
7. Aplicar Taste según DESIGN.md.
8. Implementar.
9. Revisar accesibilidad/UX con Vercel guidelines.
10. Aplicar Emil solo a motion relevante.
11. Ejecutar gates.
12. Registrar decisión/lesson reutilizable.
