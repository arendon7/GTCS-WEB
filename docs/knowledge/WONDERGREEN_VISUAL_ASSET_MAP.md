Evitar que una fotografía, render o arte histórico de la familia Wondergreen se use como si representara una presentación, formulación o empaque vigente distinto al observado.

## Reglas
1. Una imagen de producto debe coincidir con familia, formato, formulación declarada y presentación del SKU cuando se ubique junto a precio o acción de compra.
2. Una foto de otra presentación puede aparecer únicamente como imagen editorial de familia, con presentación visible o aclarada y sin inducir equivalencia comercial.
3. No recortar ni editar el empaque para ocultar una presentación, fórmula o versión que no coincide.
4. No generar mediante IA una fotografía que pueda confundirse con el empaque real para slots transaccionales.
5. En ausencia del activo exacto, conservar la representación gráfica neutral actual.
6. Un render histórico nunca se presenta como fotografía del producto vigente.
7. Cuando llegue un nuevo archivo, registrar: nombre, familia, fórmula/versión si es visible, presentación, fecha aproximada, origen, aprobación y slot web autorizado.
