Evitar que una fotografía real de la familia Wondergreen se use como si representara una presentación distinta a la observada en el empaque.

| `1000472121.png` | 2GROW líquido | 20 L | real / File Library | Puede representar 2GROW líquido 20 L cuando esa presentación tenga ficha/slot propio; **no** usar como imagen del SKU 1 L. |

## Reglas
1. Una imagen de producto debe coincidir con familia, formato y presentación del SKU cuando se ubique junto a precio o acción de compra.
2. Una foto de otra presentación puede aparecer únicamente como imagen editorial de familia, con presentación visible o aclarada.
3. No recortar ni editar el empaque para ocultar una presentación que no coincide.
4. No generar mediante IA una fotografía que pueda confundirse con el empaque real para slots transaccionales.
5. En ausencia del activo exacto, conservar la representación gráfica neutral actual.
6. Cuando llegue un nuevo archivo, registrar: nombre, familia, presentación, fecha aproximada, origen, aprobación y slot web autorizado.
