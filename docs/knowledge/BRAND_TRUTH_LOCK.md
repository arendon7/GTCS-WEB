# Brand Truth Lock · Greenatics / Wondergreen

## Regla principal
No redibujar, deformar ni reinterpretar logos oficiales.

## Fuentes canónicas incorporadas
Activos entregados directamente por Greenatics el 11-ago-2026:
- `Logo greenatics.png` · logotipo horizontal oficial.
- `Logos Greenatics-01.png` · aplicación apilada oficial.
- `Logos Greenatics.ai` · archivo maestro Adobe Illustrator con variantes oficiales.
- `wondergreen_logo.png` · logotipo oficial Wondergreen Nutrients.
- Manuales de identidad Greenatics y Wondergreen disponibles en la biblioteca documental.

## Activos web derivados
- `public/brand/greenatics-horizontal.webp`: derivado optimizado del PNG oficial, sin recomposición ni deformación.
- `public/brand/greenatics-symbol.svg`: isotipo vectorial extraído de la página oficial correspondiente del archivo Illustrator, conservando paths y colores.
- `public/brand/wondergreen-nutrients.webp`: derivado optimizado del PNG oficial, sin recomposición ni deformación.

## Reglas
- Mantener siempre relación de aspecto original.
- No alterar posición de elementos, trazos ni proporciones.
- No cambiar tipografía interna del logotipo.
- No aplicar filtros CSS para recolorear una versión oficial.
- No separar elementos del logo salvo cuando exista una variante oficial independiente, como el isotipo Greenatics.
- Se permiten únicamente aplicaciones policromáticas/monocromáticas respaldadas por el archivo maestro o manual.
- Marca: Arial Rounded MT Bold; complementaria: Arial Rounded MT.
- Paleta de referencia del manual: Pantone 627 CP, 7732 CP, 375 CP, 7404 CP y Cool Gray 1 CP.

## Implementación V0.1
Header, Home y hub Wondergreen usan desde esta versión activos oficiales. Los nombres tipográficos dejan de actuar como sustitutos principales del logotipo. Cualquier nuevo asset de marca debe partir del archivo maestro o de material entregado/aprobado por Greenatics.
