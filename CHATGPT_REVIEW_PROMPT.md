# Prompt para revisar Greenatics Web en ChatGPT

Revisa el paquete adjunto 'GREENATICS-WEB-REVIEW-2026-09-01.zip' como una versión
completa de la web de Greenatics, no como archivos aislados.

Lee primero:

1. 'REVIEW_CONTEXT.md'
2. 'README.md'
3. 'src/data/claims.ts'
4. 'src/data/services.ts'
5. Las páginas y componentes de las rutas prioritarias descritas en el contexto.

Quiero una revisión profunda desde cuatro perspectivas:

1. UX, arquitectura de información, navegación y conversión.
2. Calidad de contenidos, titulares, explicaciones y consistencia editorial.
3. Uso de imágenes, evidencia territorial y narrativa visual.
4. Rigor de claims técnicos, ambientales, agronómicos, comerciales y regulatorios.

Para cada hallazgo:

- Indica la página o archivo afectado.
- Explica el problema desde la perspectiva del visitante.
- Propón el texto, estructura o componente exacto que lo resolvería.
- Clasifica la prioridad como crítica, alta, media o exploratoria.
- Separa cambios que pueden implementarse ya de aquellos que requieren validación
  técnica, legal, comercial o agronómica.

No inventes datos. Las únicas cifras de impacto público validadas en esta revisión son
las centralizadas en 'src/data/claims.ts' y deben conservar su contexto de Yarumal.

Al final, entrega:

- Un diagnóstico ejecutivo.
- Las 15 mejoras de mayor impacto.
- Una ruta de implementación en tres iteraciones.
- Una lista de textos concretos que reescribirías.
- Una lista de imágenes que conservarías, reemplazarías o añadirías.
