# Tecnología Wondergreen

Esta ruta publica una capa explicativa entre Product Truth y la interpretación agronómica.

## Gobierno

- `organomineral`, `oclusión` y `lenta liberación` se explican como conceptos técnicos vinculados a referencias/versiones documentadas.
- La ruta no asigna automáticamente esas características a todo el portafolio.
- No publica dosis, frecuencia, compatibilidad, eficacia, duración o resultados universales.
- `Product Truth` gobierna formulación, presentación y condición comercial.
- La documentación técnica vigente gobierna características específicas de cada referencia.
- Las guías y criterios agronómicos contextualizan el uso; no sustituyen una recomendación específica.

## Jerarquía

Producto → característica → mecanismo → beneficio contextual → resultado con evidencia.

El salto entre niveles requiere soporte adicional; una característica no se convierte por sí sola en un resultado.
